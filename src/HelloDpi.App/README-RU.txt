Начиная с версии 0.6.1, HelloDpi.exe можно переносить и запускать отдельно:   нужные компоненты встроены внутрь и восстанавливаются автоматически.Приложение автоматически проверяет Discord Gateway, YouTube, настоящийTelegram MTProto, ChatGPT и Claude, перебирает встроенные профили и сохраняетлучший вариант для текущей сети. При отключении оно завершает только тепроцессы сетевого движка и туннеля, которые запустило само.Версия 0.5 ускорила YouTube в гибридном режиме. Discord, видеопотокиgooglevideo.com, изображения ytimg.com и превью ggpht.com остаются на быстромпрямом DPI-маршруте. Через Tor/Snowflake направляются только страницы ислужебные запросы YouTube и Telegram. ChatGPT и Claude используют отдельныйлокальный маршрут Psiphon с выходом через поддерживаемую страну.При первом успешном подключении приложение само открывает в Telegram ужезаполненную настройку локального SOCKS5-прокси 127.0.0.1:19050. Telegram изсоображений безопасности требует один раз нажать «Подключить». Вводить адрес ипорт вручную не нужно. После этого Telegram использует туннель при каждомзапуске Hello DPI.Перед изменением системного прокси приложение сохраняет исходные параметрыWindows. При нажатии «ВЫКЛ» или штатном закрытии они восстанавливаются. Еслипроцесс был аварийно завершён, снова запустите приложение: оно восстановитсохранённые параметры перед новым подключением.Это тестовый MVP, а не подписанный публичный релиз. Windows SmartScreen можетпоказывать предупреждение, поскольку HelloDpi.exe пока не имеет коммерческойцифровой подписи. Не добавляйте папку в исключения антивируса.Ограничение: Tor использует внешнюю добровольческую сеть и может медленнееоткрывать саму страницу YouTube. После начала воспроизведения видео загружаетсянапрямую через DPI-обход. Собственный VPS не требуется.Версия 0.6.3 разделяет туннели: Tor больше не используется для ChatGPT иClaude, поскольку сайты распознают его выходы как анонимайзер. Для ИИавтоматически запускается отдельное консольное ядро Psiphon.Обычная проверка безопасности Cloudflare распознаётся отдельно от настоящейрегиональной ошибки; в браузере она может занять несколько секунд.Версия 0.6.4 запускает Tor и маршрут ИИ одновременно, ограничивает каждый этаппо времени и автоматически пробует Нидерланды, Германию и Финляндию. Еслимаршрут ИИ не подключился, программа завершает подключение с резервным режимом,а не остаётся бесконечно на экране ожидания.Версия 0.6.5 проверяет не только страну выхода, но и настоящий ответ ChatGPT иClaude. Если сайт показывает блокировку VPN или сообщение о недоступном регионе,этот IP автоматически отклоняется и программа пробует другую страну израсширенного списка: Великобританию, США, Канаду, Францию, Германию, Финляндиюи Нидерланды. Ложный зелёный статус для заблокированных страниц больше непоказывается.Программа проверяет отдельный канал обновлений при запуске и каждые четыречаса. Вход в GitHub и аккаунт не требуются. В канале нет исходного кода иобычного ZIP-файла программы: пакет зашифрован AES-256-GCM, подписан ECDSAP-256 и дополнительно проверяется по SHA-256. По умолчанию готовое обновлениеустанавливается при закрытии программы; его также можно установить кнопкой.При неудачном запуске выполняется автоматический откат.Кнопка «ПРОВЕРИТЬ» запускает ручную проверку. Если новая версия найдена искачана, эта же кнопка меняется на «УСТАНОВИТЬ».Начиная с версии 0.6.5 канал обновлений подключается к GitHub напрямую. Поэтомупроверка обновлений не застрянет на уже закрытом локальном прокси послеаварийного завершения или смены версии.Версия 0.6.6 направляет Discord API, CDN и Gateway через тот же проверенныйAI-маршрут, если прямой DPI-обход больше не открывает Gateway. Голосовой UDP ивидеопотоки YouTube по-прежнему не отправляются в медленный HTTP-туннель.Состояние Discord теперь повторно проверяется уже после запуска туннеля.Если Hello DPI выключен, локальный SOCKS5-порт Telegram недоступен. Сначалавключите Hello DPI, затем запускайте или переподключайте Telegram.
