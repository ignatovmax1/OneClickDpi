ONECLICK DPI — MVP 0.6.6

1. Полностью распакуйте архив в отдельную папку.
2. Запустите OneClickDpi.exe и подтвердите запрос Windows UAC.
3. Нажмите центральную кнопку «ВКЛ».
4. Начиная с версии 0.6.1, OneClickDpi.exe можно переносить и запускать отдельно:
   нужные компоненты встроены внутрь и восстанавливаются автоматически.

Приложение автоматически проверяет Discord Gateway, YouTube, настоящий
Telegram MTProto, ChatGPT и Claude, перебирает встроенные профили и сохраняет
лучший вариант для текущей сети. При отключении оно завершает только те
процессы сетевого движка и туннеля, которые запустило само.

Версия 0.5 ускорила YouTube в гибридном режиме. Discord, видеопотоки
googlevideo.com, изображения ytimg.com и превью ggpht.com остаются на быстром
прямом DPI-маршруте. Через Tor/Snowflake направляются только страницы и
служебные запросы YouTube и Telegram. ChatGPT и Claude используют отдельный
локальный маршрут Psiphon с выходом через поддерживаемую страну.

При первом успешном подключении приложение само открывает в Telegram уже
заполненную настройку локального SOCKS5-прокси 127.0.0.1:19050. Telegram из
соображений безопасности требует один раз нажать «Подключить». Вводить адрес и
порт вручную не нужно. После этого Telegram использует туннель при каждом
запуске OneClick DPI.

Перед изменением системного прокси приложение сохраняет исходные параметры
Windows. При нажатии «ВЫКЛ» или штатном закрытии они восстанавливаются. Если
процесс был аварийно завершён, снова запустите приложение: оно восстановит
сохранённые параметры перед новым подключением.

Это тестовый MVP, а не подписанный публичный релиз. Windows SmartScreen может
показывать предупреждение, поскольку OneClickDpi.exe пока не имеет коммерческой
цифровой подписи. Не добавляйте папку в исключения антивируса.

Ограничение: Tor использует внешнюю добровольческую сеть и может медленнее
открывать саму страницу YouTube. После начала воспроизведения видео загружается
напрямую через DPI-обход. Собственный VPS не требуется.

Версия 0.6.3 разделяет туннели: Tor больше не используется для ChatGPT и
Claude, поскольку сайты распознают его выходы как анонимайзер. Для ИИ
автоматически запускается отдельное консольное ядро Psiphon.
Обычная проверка безопасности Cloudflare распознаётся отдельно от настоящей
региональной ошибки; в браузере она может занять несколько секунд.

Версия 0.6.4 запускает Tor и маршрут ИИ одновременно, ограничивает каждый этап
по времени и автоматически пробует Нидерланды, Германию и Финляндию. Если
маршрут ИИ не подключился, программа завершает подключение с резервным режимом,
а не остаётся бесконечно на экране ожидания.

Версия 0.6.5 проверяет не только страну выхода, но и настоящий ответ ChatGPT и
Claude. Если сайт показывает блокировку VPN или сообщение о недоступном регионе,
этот IP автоматически отклоняется и программа пробует другую страну из
расширенного списка: Великобританию, США, Канаду, Францию, Германию, Финляндию
и Нидерланды. Ложный зелёный статус для заблокированных страниц больше не
показывается.

Программа проверяет отдельный канал обновлений при запуске и каждые четыре
часа. Вход в GitHub и аккаунт не требуются. В канале нет исходного кода и
обычного ZIP-файла программы: пакет зашифрован AES-256-GCM, подписан ECDSA
P-256 и дополнительно проверяется по SHA-256. По умолчанию готовое обновление
устанавливается при закрытии программы; его также можно установить кнопкой.
При неудачном запуске выполняется автоматический откат.

Кнопка «ПРОВЕРИТЬ» запускает ручную проверку. Если новая версия найдена и
скачана, эта же кнопка меняется на «УСТАНОВИТЬ».

Начиная с версии 0.6.5 канал обновлений подключается к GitHub напрямую. Поэтому
проверка обновлений не застрянет на уже закрытом локальном прокси после
аварийного завершения или смены версии.

Версия 0.6.6 направляет Discord API, CDN и Gateway через тот же проверенный
AI-маршрут, если прямой DPI-обход больше не открывает Gateway. Голосовой UDP и
видеопотоки YouTube по-прежнему не отправляются в медленный HTTP-туннель.
Состояние Discord теперь повторно проверяется уже после запуска туннеля.

Если OneClick DPI выключен, локальный SOCKS5-порт Telegram недоступен. Сначала
включите OneClick DPI, затем запускайте или переподключайте Telegram.
