# OneClick DPI

Приватная версия OneClick DPI для Windows 10/11.

## Скачать программу

Откройте раздел **Releases** и скачайте:

- `OneClickDpi.exe` — запуск одним файлом;
- `OneClickDpi-MVP-0.6.6-win-x64.zip` — полный рекомендуемый комплект;
- `OneClickDpi-0.6.6-source.zip` — архив исходников.

Перед запуском ZIP необходимо полностью распаковать. Запускайте OneClickDpi от имени администратора.

Публичный репозиторий OneClickDpi-Updates используется только встроенным механизмом автоматического обновления.
