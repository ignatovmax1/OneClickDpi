ChatGPT, Claude and WhatsApp now use an encrypted SSH SOCKS tunnel to 185.173.144.43 instead of the unauthenticated connection to the VPS SOCKS service, which requires authentication. These routes no longer fall back to Tor.

This Windows build requires Windows OpenSSH and the current user's preconfigured `vps` SSH alias, key and verified known-host entry. No private key or password is included. On another PC, configure and verify `ssh vps` before connecting. Web traffic follows the Windows system proxy; native applications that ignore it and WhatsApp UDP calls are not covered by this change.
