Первая версия со встроенным безопасным автообновлением.

- Проверка GitHub Releases при запуске и каждые четыре часа.
- Ручная кнопка «ПРОВЕРИТЬ», которая меняется на «УСТАНОВИТЬ» после загрузки.
- Никаких аккаунтов, кнопок входа и ручных ключей доступа.
- Фоновая загрузка обновления.
- Зашифрованный AES-256-GCM пакет без публикации обычного ZIP-файла.
- Проверка ECDSA P-256, SHA-256, размера и версии пакета.
- Установка по кнопке или автоматически при закрытии.
- Автоматический откат, если новая версия не подтверждает запуск.
- Сохранён быстрый прямой маршрут для видеопотоков YouTube.
